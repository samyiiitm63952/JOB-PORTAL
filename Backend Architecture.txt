## 1️⃣ `index.js` — The Entry Point

**File:** [`index.js`](file:///c:/Users/samad/Downloads/JOB%20PORTAL/Backend/index.js)

## 3️⃣ Middleware — Request Guards

### [`isAuthenticated.js`](file:///c:/Users/samad/Downloads/JOB PORTAL/Backend/middleware/isAuthenticated.js)
**JWT Authentication guard.** Every protected route passes through this first:
1. Reads the `token` cookie from the request
2. Verifies it using `JWT_SECRET`
3. Decodes the `userId` and attaches it as `req.id`
4. Calls `next()` to pass control to the controller

### [`multer.js`](file:///c:/Users/samad/Downloads/JOB PORTAL/Backend/middleware/multer.js)
**File upload handler.** Stores uploaded files in **memory (RAM)** (not disk), so they can be sent to Cloudinary (the upload code is a TODO comment in `updateProfile`).

## 🔄 Full Request Flow (Example: Student applies for a job)

```
Client
  │
  ▼
POST /api/application/apply/:jobId
  │
  ▼
isAuthenticated middleware
  ├─ reads cookie → verifies JWT → attaches req.id
  │
  ▼
applyjob controller
  ├─ checks duplicate application
  ├─ checks job exists
  ├─ creates Application document
  ├─ pushes applicationId into Job.application[]
  └─ returns 200 JSON response
```
