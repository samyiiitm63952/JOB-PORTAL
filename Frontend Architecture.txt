## 4️⃣ `lib/utils.js` — The `cn()` Helper

**File:** [`utils.js`](file:///c:/Users/samad/Downloads/JOB%20PORTAL/Frontend/src/lib/utils.js)

```js
export function cn(...inputs) {
  return twMerge(clsx(inputs));
}
```

- `clsx` → conditionally joins class names
- `twMerge` → merges Tailwind classes without conflicts
- Used by all ShadCN UI components to safely combine class names

## 6️⃣ Components

### 🔐 `authentication/` — Auth Pages

#### [`Login.jsx`](file:///c:/Users/samad/Downloads/JOB%20PORTAL/Frontend/src/components/authentication/Login.jsx)

**How it works, step by step:**

```
1. useState manages form fields: { email, password, role }
2. changeEventHandler → updates state on every keypress using [e.target.name]
3. submitHandler:
   ├─ dispatch(setLoading(true))       ← shows spinner
   ├─ axios.POST /api/users/login      ← sends credentials
   │    └─ withCredentials: true       ← allows cookie to be saved
   ├─ on success → navigate("/")
   ├─ on error   → toast.error(message)
   └─ finally → dispatch(setLoading(false)) ← hides spinner
4. JSX shows a Loader2 spinner while loading, else shows submit button
```

#### [`Register.jsx`](file:///c:/Users/samad/Downloads/JOB%20PORTAL/Frontend/src/components/authentication/Register.jsx)

**Key difference from Login:** Uses **`FormData`** instead of JSON because it handles file uploads (profile photo).

```
1. useState: { fullname, email, password, role, phoneNumber, file }
2. ChangeFilehandler → captures file from <input type="file">
3. submitHandler:
   ├─ Builds FormData with all fields + file
   ├─ axios.POST /api/users/register  (multipart/form-data)
   ├─ on success → navigate("/login")
   └─ on error   → toast.error(message)
```

## 🔄 Full Data Flow (Login Example)

```
User fills form
      │
      ▼
useState (local form state)
      │
      ▼
submitHandler() called
      │
      ├─── dispatch(setLoading(true))  ──► Redux store.auth.loading = true
      │                                         │
      │                                         ▼
      │                                   Spinner shown in UI
      │
      ├─── axios.post("/api/users/login")  ──► Backend
      │         withCredentials: true           │
      │                                         ▼
      │                                   JWT cookie set in browser
      │
      ├─── success → navigate("/")
      │    error   → toast.error()
      │
      └─── dispatch(setLoading(false)) ──► Spinner hidden
```
